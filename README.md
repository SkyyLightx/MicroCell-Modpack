## 📖 Overview
MicroCell is a Minecraft modpack focused on extreme space efficiency and technical automation. Players are confined to a small area and must use mods like Compact Machines to progress.

## 🚀 Installation

### Client
1. Download the latest release from [CurseForge](link) or [Modrinth](link).
2. Install the recommended/latest version of **MicroCell: Survival Compressed**.
3. Place the modpack files in your `.minecraft` directory or use the launcher.

### Server
1. Download the **Server Pack** from the releases page.
2. Extract all files into an empty folder.
3. Run `run.bat` (Windows) or `run.sh` (Linux) to generate configs.
4. Accept the EULA (`eula.txt`).
5. Start the server.
